# Darling Blush — лендинг

Одностраничный сайт для мастерской сумок и косметичек ручной работы **Darling Blush** (Лиза, @gette.liza): сумки с рюшами, кросс-боди, клатчи «Бэмби» и «коровка», шопперы «барашек», косметички, кошельки. Заказ через Telegram @gette_liza и Direct @darling.blush, доставка по России.

## Структура

```
index.html            — страница (10 блоков)
assets/css/style.css  — стили
assets/js/main.js     — скрипты (без библиотек)
assets/img/           — изображения WebP + JPEG-фолбэк, иконки, OG-картинка
assets/video/         — два коротких ролика (H.264, без звука)
robots.txt, sitemap.xml, llms.txt, site.webmanifest — SEO / GEO
```

## Блоки

1. Первый экран — «полароиды» на скрепке, пятнышки «Бэмби» на фоне
2. О мастере — история Лизы и «бирка» с материалами
3. Коллекция — примеры работ со стартовыми ценами
4. Палитра — интерактивные образцы тканей, при клике меняется фото
5. Детали — разбор кросс-боди по точкам (на мобильных — подсказка под фото)
6. Прайс на бирках
7. Видео и подарочная упаковка
8. Как заказать — четыре шага
9. Отзывы — слайдер в стиле переписки (свайп, стрелки, точки, клавиатура)
10. Вопросы и ответы + финальный призыв к заказу

Блока с картой нет, потому что у мастерской нет адреса: заказы оформляются онлайн, доставка по России.

## Перед публикацией

- **Отзывы в блоке 9 — демонстрационные.** Замените их на реальные сообщения клиентов (массив `reviews` или разметка `.chat` в `index.html`).
- Замените домен `https://darlingblush.ru/` на настоящий в `index.html` (canonical, og:url, og:image, JSON-LD), `robots.txt`, `sitemap.xml` и `llms.txt`.
- Цены указаны по прайсу из соцсетей. При изменении обновите блоки «Коллекция» и «Прайс» и JSON-LD в `<head>`.
- Шрифты Poiret One, Cormorant Garamond и Manrope подключены с Google Fonts. Если без них страница грузится медленно, сохраните их локально в `assets/fonts`.

## Технические детали

- Адаптивная вёрстка от 320 px, меню-бургер на экранах ≤ 960 px, учтены safe-area для iPhone.
- Поддерживаются Chrome, Safari (iOS/macOS), Firefox, Edge, Samsung Internet и Яндекс Браузер.
- `<picture>` с WebP и JPEG, `srcset`, ленивая загрузка; видео запускается, только когда попадает в зону видимости.
- Учтены `prefers-reduced-motion`, фокус с клавиатуры, aria-атрибуты.
- Микроразметка Schema.org: Store + OfferCatalog + FAQPage. OG-разметка для превью в мессенджерах.
- Бегущих строк на странице нет.
